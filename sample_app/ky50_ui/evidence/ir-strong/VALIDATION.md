# 人脸强活体接入与耗时验证

本文件保留初次接入版的实现与测量基线；后续锁范围、Y通道优化和完整响应时间分析见[优化记录](OPTIMIZATION.md)。当前运行版本以开发指南的部署表为准。

日期：2026-11-13。新SDK接口`pvaFaceLiveIr`只用于人脸识别，掌静脉和注册流程不增加该检查。用户指定默认开启。

参数第6页新增“强活体检测”，app.conf升级v4并保留既有配置；保存后取消/清理旧任务再即时应用。该接口依赖SDK原有的人脸活体开关：开启强活体前必须开启人脸活体，强活体开启期间拒绝关闭人脸活体。关闭强活体只取消额外IR检查，不改变原RGB活体设置。

后台仅对RGB质量及身份匹配通过的候选追加IR活体，false/异常/缺IR输入均不能提交成功、记录考勤或触发继电器。同批IR Y被复制为独占完整NV12，UV补128，支持采集缓冲立即复用；每个需要确认的样本分别检查，不复用其他目标或更早样本的true结果。参数修改、离场、掌进入、切源、退出继续取消旧任务。

SDK文档明确IR接口内部与人脸Pose/Feat互斥，因此后台化不能保证检测框完全不降频；UI/采集仍是独立线程。`BIO_IR_LIVE`分别记录RGB阶段与新增IR调用墙钟时间。板端开关对照已完成，成功任务耗时接近翻倍，详见下方。

接口只返回最大IR人脸是否通过，不输出框/关键点，不能仅凭布尔值证明它与RGB识别的人是同一人。本次只绑定同一采集批次，未实现双镜头几何标定/跨模态身份关联；多人交叉及活体攻击抵抗能力不属于已验证结论。

成功任务中位数增加447.421 ms，约95%。该任务包含RGB特征/匹配及可选IR检查，**不是从人脸首次进入画面到提示成功的总时间**；表中仅统计`BIO_STAGE modality=face result=0`，不能混入快速质量失败的任务充当关闭基线。采集窗口取elapsed 140/145/150/155及175/180/185/190的STATS；最后窗口可能包含离开画面或切页边界。检测窗口对应摘录中的行号，不能拿无人时的周期比较。`ACCESS_PRESENT age_ms`从业务处理所用时间戳计时，包括考勤存储及上屏，也不能等同于纯UI绘制时间。

共9次新增IR调用，5次true、4次false。全部调用中位数409.901 ms，范围139.326～523.994 ms；其中通过的5次中位数444.098 ms，范围292.101～479.238 ms。false会阻止本次成功并需要后续样本重试，因此用户感到的额外等待可能超过单次约0.45秒。这个小样本包含进出/移动过程，不能据此计算活体准确率。bool也不能区分无人脸、框/关键点无效、推理失败或活体分数不足。

截至本次最后状态核对，正式app.conf为`strong_liveness=0`，日志只有测试时一次关闭保存；未覆盖用户手动选择。代码默认值和旧版配置升级默认值仍为1，首次部署启动日志也确认开启。恢复测试前状态应在参数第6页开启并保存，立即生效。

## 延迟来源与后续优化边界

1. 新接口是额外串行工作：原RGB质量、活体、特征和匹配完成后，重新对IR做人脸检测、关键点检查及活体。主应用已经在后台执行；预览保持约24 fps，但识别响应明显变慢，不能把此次接入描述为无感开销。
2. `libpva_face/src/api/pvaFaceRec.cpp`的`pvaFaceLiveIr`用`FaceExclusiveLock`同时持有人脸检测、特征和数据库锁；`pvaGetFacePose`需相同检测锁。IR处理时检测线程可能等待，符合本轮检测周期峰值约405 ms的现象。减少锁范围需同步审查共享模型输入/输出缓冲、配置和退出生命周期，不能直接去锁或增加线程并发调用。
3. `libpva_face/src/face/facePose.cpp`中先检测，再将全幅NV12转换为Image，然后才启动`FaceTiming("liveness_ir")`。6次该子阶段为124.436～155.779 ms；它不包含前面的检测、转换及入口锁等待。整次IR调用约0.44秒不能全算作活体模型推理，当前日志也不足以精确分摊剩余时间。
4. 后续SDK优化可先增加锁等待、IR检测、转换/裁剪、模型提交的分段计时，再评估直接NV12 ROI预处理或硬件裁剪/缩放/颜色转换，并缩小检测锁持有范围。若希望复用RGB检测框，须先解决双镜头几何映射并设计可验证的IR ROI接口，现有bool接口不具备这个能力。这些方向尚未实现或测量，不承诺可节省的时间。

本轮完成接入、默认开关、即时配置、错误阻断、主机回归与真实板端开销测量；尚未完成新IR路径的专项性能优化、多人关联或活体攻防验收。绿色成功框及提示继续等待全部检查通过后一并提交，不提前展示成功。
