# KY50 三路 RTSP 板测记录（2026-11-14）

## 交付范围

工厂页新增RTSP开关；RGB、IR、DVP同时推流，屏幕始终保留当前相机预览，无关闭预览按钮。默认RTSP关闭，不持久化；离开页面继续运行。三个路径分别为`rtsp://192.168.31.83:8554/rgb`、`/ir`、`/dvp`。RGB/IR 960×540，DVP 640×480，H.264 Baseline，15 fps，目标码率2 Mbps / 2 Mbps / 768 Kbps，无音频、无屏幕菜单或识别框，保持相机原方向。

## 已验证

1. `make -j8 package`交叉构建和打包成功；新增应用代码按`-Wall -Wextra -Werror`构建。
2. `ui_preview`完整指针回归通过：RTSP结果驱动按钮、忙碌点击抑制、离页返回、失败重试及原有菜单/用户页流程。
3. `overlay-test`、`queue-test`通过ASan/UBSan。此执行环境LeakSanitizer因ptrace失败，复测只设置`ASAN_OPTIONS=detect_leaks=0`，UBSan设置`halt_on_error=1`；保留原显示防抖与队列所有权断言。
4. 完整应用RGB预览+三路并发：30秒码流每路451帧，真实耗时约31秒，三路0解码错误。最终ELF的工厂按钮开启测试同样每路451帧，真实耗时31.06 / 31.16 / 31.26秒。
5. 本机RGB→IR→DVP切换期间远端45秒并发解码：每路676帧、约46秒、0解码错误，三路地址保持各自相机身份。该轮随后发现健康检查时间戳竞争造成误报；最终ELF已修正无符号时间差下溢，并重新做重复开关和持续运行测试。
6. 最终ELF无`--rtsp`正常启动时不推流；通过板端evdev注入坐标触发实际工厂页按钮开启。带RGB客户端点击关闭后客户端正常退出，8554端口返回连接拒绝，`/proc/soph/venc`无编码通道；普通预览恢复约24 fps。再次点击开启后三路编码恢复。
7. RTSP开启时RGB预览/显示约15 fps；DVP预览约20 fps，远端限15 fps。关闭模式正常预览约24 fps。这些是日志统计，未作为物理光学验收。
8. ION总量106954752字节，最终RGB预览+三路编码、检测运行时使用97906688字节，关闭恢复94023680字节；重复开启回到相同占用。驱动proc仍报告编码队列深度5，应用请求2且限制最多2个待取编码帧，不能将请求值写成已验证的驱动值。

9. 最终ELF第二次开启后连续60秒三路并发：RGB/IR/DVP各901帧，真实耗时60.89 / 60.89 / 60.99秒，0解码错误；期间本机从RGB切到DVP，三路继续。带客户端关闭及DVP预览下关闭后，本机普通预览均恢复；在DVP预览下重新开启，10秒三路各151帧、约11秒、0解码错误。随后恢复RGB预览并保持RTSP开启。

10. 用户现场确认：**“屏幕、三路画面及识别框均正常”**。确认问题包含屏幕预览/触控、三路镜头对应动态画面，以及手掌倾斜和离场再进入后的预览与识别框。

## 复测

```sh
python3 tools/check_rtsp.py 192.168.31.83 --seconds 60
```

工具同时启动三个TCP客户端，不保存现场图像，检查解码错误、帧数和真实耗时，防止仅凭标称15 fps或媒体时间误判实时性。开发日志位于`build/rtsp/`，最终板端日志`/tmp/ky50-ui-rtsp-final.log`。

## 边界

自动化注入坐标与用户现场确认分别记录；用户已确认屏幕、三路画面及识别框正常。该确认不替代定量光学测试、识别准确率或活体攻击测试。本轮未做实际断网/拔线、UDP、长期老化、多电脑负载或固件冷启动验证。DVP仍要求已确认的swapped时钟接线。
